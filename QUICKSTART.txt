📦 DOWNLOAD LOCATION:
   /workspaces/default/code/jaanmitr-ai-project.tar.gz

📝 INSTALLATION STEPS:

1. Extract the archive:
   tar -xzf jaanmitr-ai-project.tar.gz
   cd jaanmitr-ai-project

2. Install dependencies:
   npm install
   (or use: pnpm install / yarn install)

3. Start development server:
   npm run dev

4. Open in browser:
   http://localhost:5173

🚀 BUILD FOR PRODUCTION:
   npm run build
   (Output will be in /dist folder)

📁 PROJECT STRUCTURE:
   ├── src/
